# SESSION_CONTEXT

The living context for this project. What it is, why it exists, and where we are right now.

## What this is

`claude-app-experience-kit` — a forkable, scripted-first clone of the **Claude app** (`claude.ai`) interface. The goal is a faithful reproduction of the Claude app's chrome and interactions so teammates can fork this repo and build their own experiences (starting with Salesforce merchant ones, following the Anthropic × Salesforce partnership) on top of it without rebuilding the UI.

## Guiding principles

- **Scripted-first, API-ready.** Interactions play back authored scripts by default; a clean provider seam lets a real Claude API drop in later.
- **Forkability is the point.** Clear structure and a simple "author a new experience" path beat cleverness.
- **Motion matters.** Streaming, thinking states, transitions, and loading states must feel buttery-smooth.

## Who uses it

- Somnath (owner) — designing Claude app experiences for the Salesforce partnership.
- Future: teammates fork it to build their own experiences / project demos.

## Terminology & behavior notes

- **Main stage** = the right region (the non-sidebar area). This is where a **mock chat** will be prototyped.
- **"New" resets the main stage.** Clicking **New** in the sidebar must reset the main stage back to its original/empty chat state (back to 0), so the scripted experience can be replayed from the start. To hold when we build main-stage content — not yet implemented.
- **Empty-state → chat transition (settled; wiring pending).** On first send the UI **instantly swaps** (no center→bottom glide — this supersedes the earlier "animates from center to the bottom" note): the incognito button **disappears**, the **in-chat box appears bottom-anchored**, the typed text lands as a **right-aligned bubble**, and the **thinking state** begins. Thinking → response is **snappy** (pulsing Claude spark + contextual phrases → response appears; no fade). See DESIGN_DECISIONS (2026-09-29, 2026-09-30).
