# CHANGE_LOG

Chronological record of changes. Newest at the top.

## Versioning — `MAJOR.MINOR.PATCH`

- **MAJOR** (`X.0.0`) — large feature.
- **MINOR** (`0.X.0`) — small addition.
- **PATCH** (`0.0.X`) — bug fix / copy fix.

## Rules

- **Version only at commit/push.** Between commits, accumulate changes under a single **`## Unreleased`** heading (plain bullets). When we commit or push, rename `Unreleased` → the new `X.Y.Z` + date/time and open a fresh `Unreleased`. Keeps versions meaningful.

- Update this log **before session cutoff and before any commit or push.**
- Every versioned entry includes: **version, date, time, kind of change,** and any other major details.

Entry format:

```
## Unreleased        ← becomes the next version at commit time
- details

## X.Y.Z — YYYY-MM-DD HH:MM TZ
**Kind:** large feature | small addition | fix
- details
```
